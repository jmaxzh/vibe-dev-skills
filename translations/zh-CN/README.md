# 中文维护译文

本目录仅帮助开发者理解与维护，与[英文项目说明](../../README.md)对应。唯一可安装、执行的技能位于英文 `skills/`，不进行运行时语言切换。

| 技能 | 中文维护译文 | 英文原文 |
| --- | --- | --- |
| SDLC 工作流 | [译文](skills/sdlc-workflow/SKILL.zh-CN.md) | [原文](../../skills/sdlc-workflow/SKILL.md) |
| 指令与文档设计 | [译文](skills/sdlc-instr-doc-design/SKILL.zh-CN.md) | [原文](../../skills/sdlc-instr-doc-design/SKILL.md) |

| MySQL 设计 | [译文](skills/sdlc-mysql-design/SKILL.zh-CN.md) | [原文](../../skills/sdlc-mysql-design/SKILL.md) |
| CC Connect 集成 | [译文](skills/cc-connect-integration/SKILL.zh-CN.md) | [原文](../../skills/cc-connect-integration/SKILL.md) |

英文规则、条件、示例或引用变化时，同一次变更中同步译文。中文提案先落实到英文源，再同步译文；译文不独立定义行为，差异以英文为准。标识符、命令、配置键和协议名称保持一致。

脚本及测试只在[英文 CC Connect 技能目录](../../skills/cc-connect-integration/scripts/)维护；本文档体系中的相对执行命令以英文技能目录为工作位置，不复制代码到译文目录。

参阅[维护规则](AGENTS.zh-CN.md)、[分发说明](docs/distribution.md)、[提交准备](docs/submission.md)和[验证记录](docs/verification.md)。
